# Experiment Summary

## Experiment

E05 - Flask Web Application

---

## Goal

Deploy the optimized cyber attack detection model into an interactive web interface.

---

## Model

Optimized XGBoost (Generated in E03)

---

## Explainability

The application integrates SHAP visualizations generated in E04 to explain model predictions.

---

## Features

- Upload CSV datasets
- Automatic attack prediction
- Prediction statistics
- Pie chart visualization
- Bar chart visualization
- Download prediction results
- SHAP Summary visualization
- SHAP Feature Importance visualization
- SHAP Waterfall visualization

---

## Outcome

The Flask application successfully provides an end-to-end cyber attack detection platform combining prediction accuracy with explainable artificial intelligence.
