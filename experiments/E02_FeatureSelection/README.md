# Experiment 02 – Feature Selection

## Objective

Evaluate the influence of feature selection on the performance of the selected baseline model (XGBoost).

Random Forest feature importance was used to rank all features.

Five different feature subsets were evaluated.

## Feature Sets

- All Features
- Top 30
- Top 25
- Top 20
- Top 15

## Evaluation Metrics

- Accuracy
- Precision
- Recall
- F1-score
- Training Time
- Prediction Time

## Output Files

feature_importance.csv

selected_features.csv

feature_selection_results.csv

metrics_table.xlsx

trained_models/

figures/

confusion_matrices/

## Conclusion

The experiment investigates whether reducing the feature space can maintain predictive performance while improving computational efficiency.
